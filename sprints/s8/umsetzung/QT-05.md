## Befunde auf API-Ebene (gemessen, `fehlerfaelle_api.txt`)
1. **Ablehnungen mit Code (0 stumm):** `schon_lizenziert`, `unbekannter_ort`, `gleicher_ort`, `gesperrt` (Lok/W10), `guthaben_reicht_nicht` (Lizenz und Fuhrwerk), `keine_lizenzierbare_industrie` (Lizenz für ein Dorf).
2. **Stumm = Kredit:** `kredit_aufnehmen()`/`kredit_tilgen()` liefern bei Ablehnung nur `0`, keinen Grund (Sperre vor Minute 12, Rahmen voll, Kasse zu klein). F4.1–F4.3 muss die UI aus dem Zustand ableiten. Die Session zählt das als „stumm“ (1 in Loop L2, gewollt gezeigt).
3. **Lücken gegenüber AT-14 (die API lehnt NICHT ab, das Fuhrwerk wird gekauft, der Fix läuft, der Ertrag bleibt 0):**
   - F2.3 Quelle ohne Lizenz (Hof Hasenwinkel ohne Lizenz → Erlenmühle: `ok`),
   - F2.4 Ziel nimmt Ware nicht an (Getreide Kuppenhof → Erlenbach: `ok`),
   - F2.2 Quelle liefert nichts (Erlenbach → Lindenfurt: `ok`).
   In `fehlerfaelle_api.txt` Teil 2 gemessen: 3 solche Fuhrwerke, nach 5 min Ertrag 0 $, Kasse 4.136 $. **AT-08 muss diese Fälle in der UI abfangen (oder Felix in `linie_anlegen`).** Teil 2 ist als Wächter geschrieben: bekommt die API Guards, wird die Session rot und die Zeilen werden bewusst auf `erwarte fehler==<code>` umgestellt.
4. F2.1 „keine Verbindung“ ist auf der Prototyp-Karte **nicht testbar**: alle 5 Stationen sind verbunden (gemessen, Pfade zwischen allen Paaren vorhanden). Der Fall gehört in einen synthetischen Test oder entfällt mit D3 (kein Bau in S8).
5. F2.6 „Linie gibt es schon“: Die API macht daraus bewusst ein weiteres Fuhrwerk (AT-02). Die UI-Text-Variante „Füge ein Fuhrwerk hinzu“ ist reine UI.

## Grenzen
- Die Session prüft die API, **nicht die UI**. „Loop L2 grün“ heißt nicht „L2 für Basti spielbar“.
- `kapital` setzt `eco.cash_cent` direkt (Testwerkzeug, nur in `tests/`; der statische Kassen-Check W12 prüft `tests/` nicht).
- Prüfsumme je Session steht in `state.md`; ein Doppellauf-Vergleich ist nicht eingebaut (die Sim ist im Bot-Test zweimal bit-gleich gemessen, s. QT-03).
- Nur Fuhrwerk-Kategorie; `linie` nimmt `def_id` als 3. Argument (z. B. `frachtwagen_e1` ab 1830).
